# زاجل | ZAJEL

تطبيق Android لإدارة وإرسال الرسائل إلى قوائم المستلمين، بواجهة عربية وفرنسية.

## التقنية المستهدفة
- Kotlin وJetpack Compose وMaterial 3
- الحد الأدنى Android 8.0 (API 26)
- Room لتخزين البيانات محلياً
- Android SMS APIs لدعم إرسال الرسائل عبر شرائح SIM
- WhatsApp Business Cloud API عبر خادم آمن
- GitHub Actions لبناء التطبيق

## حالة المشروع
هذه بداية تأسيسية وليست إصداراً إنتاجياً. يجب استكمال ربط الواجهات بخدمات الإرسال، وإدارة موافقات المستلمين وإلغاء الاشتراك، والاستيراد، وسجل الرسائل، والاختبارات قبل الاستخدام الفعلي.

## الأمان
لا تضع رموز WhatsApp أو مفاتيح API داخل تطبيق Android. يجب تنفيذ استدعاءات WhatsApp Business من خادم آمن، مع احترام موافقات المستلمين وطلبات إلغاء الاشتراك.

## البناء
يتطلب JDK 17 وAndroid SDK المناسب. بعد إضافة ملفات Gradle ومصدر التطبيق، يمكن تشغيل:
```bash
gradle --no-daemon :app:assembleDebug
```
