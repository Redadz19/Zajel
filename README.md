# زاجل | ZAJEL

تطبيق Android لإدارة المستلمين وإرسال رسائل SMS، بواجهة عربية وفرنسية.

## التقنية
- Kotlin وJetpack Compose وMaterial 3
- الحد الأدنى Android 8.0 (API 26)
- Room لتخزين المستلمين محلياً
- Android SMS APIs لإرسال الرسائل عبر شريحة SIM
- GitHub Actions لبناء التطبيق

## الوظائف الموجودة حالياً
- إضافة المستلمين يدوياً مع تسجيل الموافقة.
- استيراد جهات الاتصال وملفات CSV.
- منع تكرار أرقام الهواتف.
- تسجيل الموافقة وإيقاف استقبال الرسائل.
- إرسال SMS بشكل فردي بعد تأكيد المستخدم.
- واجهة عربية وفرنسية.

## خارج نطاق المشروع
هذا التطبيق مخصص لـ SMS فقط. لا يتضمن WhatsApp أو WhatsApp Business أو أي تكامل مع Meta.

## ما يزال قيد التطوير
- اختيار شريحة SIM عند توفر أكثر من شريحة.
- سجل الرسائل وحالات الإرسال والتسليم.
- تحسين التحقق من صلاحيات الإرسال واختبارات الأجهزة.
- دعم استيراد Excel بصيغة XLSX.

## الأمان والامتثال
لا ترسل رسائل إلا إلى مستلمين وافقوا فعلياً على تلقيها. احترم طلبات إيقاف الرسائل وقواعد مشغل الاتصالات والقوانين المحلية. استيراد رقم من جهات الاتصال أو CSV لا يعني الحصول على موافقة صاحبه.

## البناء
يتطلب JDK 17 وAndroid SDK المناسب. يمكن تشغيل:
```bash
gradle --no-daemon :app:assembleDebug
```

هذا المشروع في مرحلة التطوير وليس إصداراً إنتاجياً معتمداً.
